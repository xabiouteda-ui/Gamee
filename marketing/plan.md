# Plan de 8 semanas (desde el lunes 5 de octubre de 2026)

Objetivo: tráfico orgánico en español y primeros enlaces. Ritmo realista para una persona: **30–45 min al día**.
Cada semana tiene 1 cosa principal (⭐) y tareas cortas. Marca lo hecho con ✅.

## Antes de empezar (esta semana)
- [ ] Fusionar la PR y comprobar que `https://herramientaslibres.es` carga con HTTPS (Settings → Pages → Enforce HTTPS).
- [ ] **Google Search Console**: propiedad de dominio (registro TXT en tu DNS) → enviar `https://herramientaslibres.es/sitemap.xml`.
- [ ] **Bing Webmaster Tools**: importar desde Search Console (1 clic). IndexNow ya avisa solo a Bing.
- [ ] Rellenar tus datos reales en `site.config.json` (aviso legal/contacto). Lo necesitan AdSense y los directorios.
- [ ] GoatCounter: crea la cuenta y pon el código en `site.config.json` → `goatcounter` (ver README).
- [ ] Canal de Telegram creado con los secretos puestos (README → «Canal de Telegram»).

## Cada día (5–10 min)
- Mira que el mensaje de Telegram de las 20:40 ha salido (si falla, *Actions → Run workflow*).
- Responde comentarios de los Shorts y los foros donde hayas escrito.

## Cada semana (15 min)
- Search Console → Rendimiento → consultas: si una búsqueda tiene impresiones pero pocos clics, cambia el título
  de esa página (o dímelo y lo hago).
- Una publicación de valor en Telegram además del aviso diario ([telegram.md](telegram.md)).

## Qué medir
| Métrica | Dónde | Meta orientativa |
|---|---|---|
| Páginas indexadas | Search Console → Indexación | Las ~48 del sitemap |
| Clics orgánicos/semana | Search Console | Que crezcan cada semana |
| Suscriptores Telegram | Canal | Que crezcan cada semana |
| Enlaces entrantes | Search Console → Enlaces | 10+ dominios distintos al final |

No pongo cifras de tráfico objetivo: con una web nueva no hay base para estimarlas sin inventar.
